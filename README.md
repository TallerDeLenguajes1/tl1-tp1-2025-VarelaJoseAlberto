### ¿Por qué es conveniente incluirlo?

Es conveniente incluirlo por el hecho que podemos excluir los archivos que no deseamos incorporar en nuestro repositorio lo cual nos permite mantener limpio y organizado.

### ¿Cuándo se debe hacer?

Cuando se quiere evitar incluir archivos como codigo compilado, archivos generados durante tiempo de ejecicion, algun tipo de archivo especifico, etc.

### ¿Cómo configuraría el archivo .gitignore?

1. Crearia un archivo de text y le asignaria el nombre ".gitignore"
2. editaria el archivo segun sea necesario 
    - armaria bloques con su respectivo comentario para los diferentes tipos de archivos que contendra mi proyecto
